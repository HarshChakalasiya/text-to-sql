# Financing Programs

A financing program is a buyer-sponsored SCF facility that defines currency, maximum tenor in days, and discount rate in basis points. Only invoices for that buyer should be financed under the buyer's programs.

Program status:
- active: new financings allowed
- paused: temporarily not accepting new financings

Programs help answer questions such as average discount rates by buyer, utilization of facilities, and which programs have the most disbursed financings.
